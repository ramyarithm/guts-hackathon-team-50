# GUTS Hackathon — Team 50

Team 50's workspace for the GUTS Hackathon at the University of Glasgow.

## Project

Project idea, final name and technology stack: to be agreed by the team.

## Get started

```bash
git clone https://github.com/2779835G/guts-hackathon-team-50.git
cd guts-hackathon-team-50
git switch -c feature/your-feature
```

Add installation and run commands here once the stack is chosen.

## Working together

1. Pick a small task and create an issue.
2. Work on a branch such as `feature/menu` or `fix/controls`.
3. Commit and push your branch, then open a pull request into `main`.
4. Ask a teammate to review and keep `main` ready to demo.

Never commit API keys or passwords. Keep local configuration in `.env`; share variable names in `.env.example`.

## Structure

- `src/` — application code
- `assets/` — images, sounds and other assets
- `docs/PLAN.md` — MVP, task allocation and demo checklist
